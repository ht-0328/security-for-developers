🃏 復習カード

設問を見たら、解答を表示する前に自分で答えを出してください（声に出すとより効果的です）。思い出す行為そのものが記憶を強化します（想起練習）。

🔬3つの練習形式
カード
1枚ずつ解答します。正答したカードは次の出題までの間隔が段階的に広がり（当日 → 1日 → 3日 → 7日 → 14日 → 30日）、答えられなかったカードは最初の段階に戻って同じ回の最後に再出題されます。答えが出ないときは「ヒント」で解答の冒頭だけを3秒間確認できます。
設問一覧
設問だけを一覧表示します。移動中などの短い時間に、上から順に答えを思い出し、確認したいものだけ開きます。
就寝前の想起
当日に取り組んだカードと、最近答えられなかったカードを表示します。就寝前に設問だけを確認し、画面を閉じてから思い出します。

記録はこのブラウザに保存されます。
