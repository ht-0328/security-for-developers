守るもの・よくある穴・まずこれだけ守る10のルール・学ぶ順番を、専門用語に定義を添え、図と想起練習でまとめています。難しい理屈より「見たら気づける」「明日から手が動く」ことを目標にしています。

本サイトの方針

① 開発者の守備範囲に絞る

セキュリティ全体は広大ですが、開発者が日々触るのはコード・部品・設定・運用の4つです。暗号理論や攻撃ツールの使い方には深入りしません。

② 「何が起きる → なぜ → どう防ぐ → どう確かめる」の順

攻撃名の暗記ではなく、事故の形と原理から入り、危険なコードと安全なコードを並べて見せます。

③ 読み返すより思い出す

章末の想起練習は本文を見ずに答えます。復習日はサイトが自動で計算します（間隔反復）。

⚖️練習は、自分のものか許可された環境だけで

本サイトで学ぶ攻撃の仕組みを、自分の管理下にないシステムに対して試すことは、不正アクセス禁止法などに触れる犯罪です。「調べるだけ」「診断のつもり」でも許されません。練習は自分で立てた環境や、練習用に公開されている教材（学び方で紹介）で行ってください。
