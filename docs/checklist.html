✅ 開発者のチェックリスト

「難しいことは抜きにして、これだけ見ておけばよい」項目を、設計・実装・リリース前・運用の4つの場面に分けました。各項目は第2章の10のルールを現場の作業に落としたもので、根拠と直し方は各章にリンクしています。チェックはこのブラウザに保存されます。

🔑使い方
  1. プロジェクト名を入れ、場面ごとに該当する項目を確認してチェックする。わからない項目は「→ 第◯章」で根拠を読む。
  2. 「Markdown でコピー」して、プルリクエストの説明やチケットに貼る。チームで同じ項目を見る習慣ができる。
  3. 該当しない項目（例：Cookie を使わない API）は、チェックせず「該当なし」と PR に書けばよい。
